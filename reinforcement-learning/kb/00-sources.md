| ID | Citation | Pages | Frequency actually tested | What it contributes |
|----|----------|-------|---------------------------|---------------------|
| S1 | LazyProgrammer (2017) *Artificial Intelligence: Reinforcement Learning in Python* — epub | ~340k chars, ~16 docs | [BOTH] toy envs | Gentle intro: bandits, MDP, DP, Monte Carlo, TD, Q-learning; Tic-Tac-Toe code. Prerequisite for everything else. |

| S3 | Hilpisch (2024) *Reinforcement Learning for Finance — A Python-Based Introduction*, O'Reilly, ISBN 9781098169145 | 215pp, 10 chapters | [BOTH] — demos use daily synthetic + historical bars but §3.3 "Where the analogy fails" explicitly discusses intraday vs EOD and data scarcity | Backbone of KB: Bayesian learning → DQL (CartPole) → Finance env → simulated/generated data → Ch6 trading, Ch7 hedging, Ch8 allocation, Ch9 execution (actor-critic). Self-contained Gym envs + DQLAgent class included. |

Best "daily close" DRL baseline in folder. |
| S5 | Avramelou, Nousi, Passalis, Tefas (2024) *Deep reinforcement learning for financial trading using multi-modal features*, ESWA 238, 121849 | 10pp | [CLOSE] daily OHLC + daily sentiment, crypto assets, PnL reward | Multi-modal embedding fusing price + sentiment; attention/weighting of modalities without retraining; compares PPO-style and other DRL variants. Shows sentiment helps *if* fused via embeddings (not naive concatenation). |
| S6 | Si, Li, Ding, Rao (2017) *A Multi-Objective Deep Reinforcement Learning Approach for Stock Index Futures' Intraday Trading*, IEEE ISCID (6pp) | 6pp | **[INTRADAY]** stock-index futures, intraday bars, transaction cost inside reward, multi-objective = mean daily profit vs volatility | Only paper with explicit intraday DRL pipeline in folder: deep feature learner (DNN) → LSTM policy for continuous actions in [-1,1], dual objective `U = α·mean(DR) - β·std(DR)` where `DR` is daily cumulative reward; balances profit and risk intraday. |

## Quick frequency legend per source

- **[CLOSE] validation:** S2, S4, S5 test on daily closes/bars. Their methods *port* to intraday but would need order-book/OHLC scaling and cost recalibration (see Ch.04).
- **[INTRADAY] validation:** S6, S7 only credible intraday evidence in folder.
- **[BOTH] theory/code:** S1, S3, S8 are agnostic; S3's Ch.4–5 data augmentation is especially relevant when you move from close to intraday and discover you still lack data.
