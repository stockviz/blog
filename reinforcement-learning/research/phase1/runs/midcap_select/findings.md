- The TDQN failure is **regime-independent**: nearly identical Sharpe on a
  higher-vol, momentum-flavored midcap index (the MIDCAP SELECT closes exist
  from 2004, OHLC only from 2022 — used close-only loader). Same root cause:
  200 flips/yr × 25bps ≈ 50%/yr drag.
- tdqn_art again beats tdqn_real and random — the S4 augmentation + learning
  hierarchy reproduces on the second instrument.
- Note: the select index B&H (+0.80) beat NIFTY 50 B&H (+0.64) over 2015+,
  and MA-cross was WORSE on select (+0.58 vs +0.76) — the midcap index's
  higher vol punishes the trend rule; a stronger argument for fixing the RL
  reward (R1.2) rather than abandoning the instrument.
