1. **The churn mechanism is FIXED by reward × cost** — this is the R1.2 win:
   churn@25 and pnl@5 learn to HOLD (97% / 92% long, ~24-58 flips/yr),
   full-window Sharpe goes -2.08 → +0.19 / +0.30, MaxDD 98% → 27% / 29%.
2. **DSR as immediate reward is confirmed broken**: dsr@5 churns 198
   flips/yr even at 5bps — the differential-Sharpe reward rewards activity,
   not net return. Drop it for daily; keep only as a diagnostic.
3. **Cost level steers the learned policy**: at 25bps a churn-averse agent
   rationally goes FLAT (pnl@25: 95% flat — trading is not worth it);
   at 5bps it goes long (pnl@5: 92% long). 25bps is the equity-book stress
   case; 5bps is the index-futures regime where RL can act at all.
4. **The remaining gap is INFORMATION, not churn**: the best arms hold long
   like B&H (vol ~16%, MaxDD ~27-29%) while MA-cross de-risks (vol 11%,
   MaxDD 20%) — the z-scored return window gives the agent no trend/regime
   feature. This is precisely R1.3's remit (state design: +VIX, +TVT-HMM
   p_off, +vol regime). Action persistence (capped per-day delta) is a
   secondary knob now that churn is ~24 flips/yr.
